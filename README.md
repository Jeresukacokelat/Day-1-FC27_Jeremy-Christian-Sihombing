## Deskripsi Repository
Repository adalah sebuah tempat penyimpanan project di GitHub. Di dalamnya ada semua file project yaitu berupa kode, dokumen dan gambar beserta riwayat perubahan dari awal dibuat.

## Tujuan dan Kegunaan Repository
- Dapat menyimpan file project secara online sehingga aman dan dapat diakses dari mana saja.
- Bisa mencatat riwayat perubahan secara real time, jadi setiap revisi bisa dilacak dan dikembalikan kalau ada kesalahan.
- Memudahkan kerja tim, karena orang-orang bisa berkontribusi dalam project yang sama.

## Dokumentasi Kegiatan Workshop

### Rangkuman Materi

&emsp;&emsp;Prompt engineering adalah cara merancang instruksi agar AI memberikan jawaban yang tepat, relevan, dan layak digunakan. Prompt adalah instruksi atau masukan yang diberikan kepada model AI, dan semakin spesifik serta kaya konteks sebuah prompt, semakin baik pula hasilnya. Prompt yang baik umumnya terdiri dari Role, Task, Context, dan Format, dengan manfaat berupa peningkatan performa model, berkurangnya bias dan respons yang offensive, hasil yang lebih terkontrol, serta pengalaman penggunaan yang lebih baik.

&emsp;&emsp;Git adalah sistem version control terdistribusi yang melacak siapa, kapan, dan apa saja yang berubah pada sebuah file secara lokal, sedangkan GitHub adalah platform berbasis web yang berfungsi untuk menyimpan repository Git secara online dan mendukung kolaborasi antar usernya. Dalam alur kerjanya, Git memiliki tiga area, yaitu working directory sebagai salinan proyek yang sedang dikerjakan, staging area sebagai tempat menampung perubahan yang akan masuk ke commit berikutnya, dan .git directory sebagai tempat Git menyimpan metadata dan database proyek.

&emsp;&emsp;Command dasar yang dipelajari meliputi `git init` untuk memulai repository, `git add .` untuk memindahkan file ke staging area, `git commit -m "message"` untuk menyimpan perubahan, `git remote add` untuk menambahkan remote repository, `git push origin main` untuk mengirim perubahan, `git pull origin main` untuk mengambil perubahan, dan `git clone` untuk menyalin repository.

### Poin-poin penting atau pengetahuan baru yang dipelajari saat workshop
Dari workshop Day 1, ada beberapa hal baru yang saya pelajari :
1. Kualitas jawaban AI itu sangat dipengaruhi oleh kualitas prompt yang diberikan
   
&emsp;Prompt yang singkat dan tanpa konteks cenderung menghasilkan jawaban yang tidak diinginkan, sedangkan prompt yang memiliki Role, Task, Context, dan Format menghasilkan jawaban yang lebih terarah dan bisa langsung digunakan.

2. Git dan GitHub adalah dua hal yang berbeda

&emsp;Git adalah alat version control yang bekerja secara lokal di komputer, sedangkan GitHub adalah platform online untuk menyimpan repository dan berkolaborasi.

3. Alur kerja Git

&emsp;Terdiri dari working directory, staging area, dan repository, serta command dasar seperti `git init`, `git add`, `git commit`, dan `git push` untuk mengirim perubahan dari komputer ke GitHub.
